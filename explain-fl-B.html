問1第1章 テストの基礎シラバス 1.1ID 1-12
ソフトウェアを実行せずに行う静的テストに含まれるものの組み合わせはどれか。
  1. A　静的解析とリグレッションテスト
  2. B　コンポーネントテストと静的解析
  3. C　レビューと静的解析
  4. D　レビューと探索的テスト
解答と解説
正解：C　レビューと静的解析
テストには動的テスト（ソフトウェアの実行を伴う）と静的テスト（実行を伴わない）がある。静的テストにはレビューと静的解析が含まれる。

  3. C　組織外のテスト担当者が必ず行う

問3第1章 テストの基礎シラバス 1.2.3ID 1-17
故障の原因について、正しい記述はどれか。
  1. A　欠陥はコードにだけ存在し、要件仕様書やテストスクリプトの誤りは欠陥ではなくエラーと呼ぶ
  2. B　故障はエラーや欠陥だけでなく、放射線や電磁場などの環境条件によって起きることもある
  3. C　故障はすべて人間のエラーで作り込まれた欠陥が原因であり、環境条件は故障の原因に含まれない
  4. D　欠陥を含むコードが実行されると故障が発生するので、欠陥の数と故障の数は常に一致する
解答と解説
正解：B　故障はエラーや欠陥だけでなく、放射線や電磁場などの環境条件によって起きることもある
故障の原因はエラーや欠陥だけではなく、環境条件もありうる。欠陥の中には、実行すれば必ず故障になるもの、特定の状況でしか故障にならないもの、絶対に故障にならないものがある。欠陥は要件仕様書やテストスクリプトなどのドキュメントにも存在する。

  2. B　テストを最初に書き、そのテストを満たすコードを書いてから、テストとコードをリファクタリングする
